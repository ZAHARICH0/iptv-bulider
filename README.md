# IPTV Builder 1.0 BETA

Простой браузерный генератор M3U на HTML, CSS и JavaScript.

## Запуск
1. Распакуй ZIP в отдельную папку.
2. Открой `index.html` в браузере.
3. Напиши запрос или выбери фильтры и нажми «Создать M3U».

Если браузер блокирует загрузку списков при открытии `index.html` напрямую, размести папку на статическом HTTPS-хостинге. Проект не требует собственного сервера, если источник доступен из браузера.

## Источник
Публичные плейлисты IPTV-org:
- Все каналы: https://iptv-org.github.io/iptv/index.m3u
- По странам: https://iptv-org.github.io/iptv/countries/{код}.m3u
- По категориям: https://iptv-org.github.io/iptv/categories/{категория}.m3u
- По языкам: https://iptv-org.github.io/iptv/languages/{код}.m3u

## EPG и архив
- Переключатель EPG добавляет XMLTV-ссылку только если пользователь ввёл её в поле.
- Архив добавляет `catchup="default"` и `catchup-days`. Это лишь метаданные: просмотр архива зависит от самого потока/сервера и IPTV-плеера.
- IPTV-org публикует каталог потоков; не все потоки гарантированно работают.

## История
Хранится в localStorage этого браузера и устройства (до 20 плейлистов). Очистка данных сайта/браузера может удалить историю.

## Ограничения beta
- Свободный текст обрабатывается простыми правилами и не является настоящей AI-моделью.
- Фильтры по нескольким источникам пересекаются по точному URL, поэтому при несовпадении метаданных результат может оказаться пустым.
- Некоторые браузеры и локальные файлы могут блокировать запросы к источнику из-за CORS.
